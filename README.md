# Projet de stage technicien — IZiForM

## Présentation du projet

Ce projet a été réalisé dans le cadre de mon stage technicien à l'Institut Zitouna de Formation (IZiForM), situé à Zarzis, en Tunisie.

L'objectif est de développer un site web pour un institut de formation professionnelle afin de présenter ses formations et de faciliter l'accès aux informations pour les visiteurs.

## Objectifs
- Développer une interface web simple et intuitive.
- Présenter l'institut et ses formations.
- Mettre en pratique mes compétences en développement web.
- Découvrir la gestion de versions avec Git et GitHub.

## Fonctionnalités

Les fonctionnalités dépendent de la version actuelle du projet :
- Présentation de l'institut.
- Consultation des formations.
- Présentation des diplômes.
- Galerie de photos.
- Formulaire de contact.

## Technologies utilisées

À compléter selon les technologies réellement utilisées dans le projet :
- HTML et CSS
- PHP
- MySQL
- Bootstrap
- JavaScript
- Git et GitHub

## Installation

1. Cloner le dépôt GitHub.
2. Placer le projet dans le dossier `htdocs` de XAMPP.
3. Démarrer Apache et MySQL.
4. Créer la base de données et importer le fichier SQL, s'il est fourni.
5. Configurer la connexion à la base de données.
6. Ouvrir le projet dans le navigateur avec localhost.
